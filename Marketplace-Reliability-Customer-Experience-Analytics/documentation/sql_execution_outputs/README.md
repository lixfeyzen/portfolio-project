# SQL Execution Outputs

This folder is reserved for local SQL workflow outputs generated by the automation scripts.

Generated outputs may include:

- environment check reports
- import summaries
- SQL validation result CSV files
- workflow logs

Most generated files in this folder are ignored by Git because they can contain local machine paths, usernames, or environment-specific details. Keep this README as the portable project note.

To regenerate local outputs:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\auto_setup_sql_workflow.ps1 -ServerInstance localhost
```

If SQL Server authentication fails, review `environment_check.md` and `run_sql_workflow.log` locally.
