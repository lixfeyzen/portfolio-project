# Outputs Folder

The SQLite database is generated locally in this folder.

Expected local database:

```text
outputs/oulad_pipeline.db
```

The database is excluded from Git because it can be recreated from the raw OULAD files.

The README includes a DB Browser for SQLite preview image so reviewers can see the generated schema without downloading or committing the large `.db` file.

Reporting CSV outputs are generated by:

```bash
python scripts/05_export_reporting_tables.py
```

Small reporting output CSV files may be committed only if each file is under 5 MB. Large generated files should remain local and be documented instead.
