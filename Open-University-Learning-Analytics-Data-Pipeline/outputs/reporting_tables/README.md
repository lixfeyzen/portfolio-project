# Reporting Tables

This folder stores reporting-ready CSV exports generated from SQLite views.

Expected outputs:

- `course_registration_summary.csv`
- `student_engagement_summary.csv`
- `assessment_performance_summary.csv`
- `vle_activity_summary.csv`
- `student_outcome_summary.csv`
- `at_risk_student_indicators.csv`

If an output file becomes large, keep it local and document the output instead of committing it to Git.
