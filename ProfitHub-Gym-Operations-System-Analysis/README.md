# ProfitHub — Gym Operations & Membership Management System

ProfitHub is a System Analyst portfolio case study for an internal gym operations system. It documents how a small-to-medium gym can move from manual records, disconnected spreadsheets, WhatsApp follow-ups, and paper notes into a structured system for members, subscriptions, payments, class bookings, attendance, and owner reporting.

This is a System Analyst case study, not a finished application. No production deployment, real client data, payment gateway integration, or member mobile app is included.

## Business Problem

Many gyms manage daily operations with informal tools. This creates unclear member status, missed payment follow-ups, inconsistent revenue records, class schedule conflicts, trainer double-booking, and limited visibility for owners.

## System Goal

Design an internal gym operations system that helps gym owners, admins, and trainers manage core operational data in one structured workflow.

## Target Users

- Owner / Manager
- Admin / Receptionist
- Trainer
- Member as a data entity and booking participant only, not a full MVP application user

## MVP Modules
