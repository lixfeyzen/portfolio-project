# Diagrams

This folder contains Mermaid diagram source files for the ProfitHub system
analysis case study.

The diagrams are conceptual planning artifacts.

They can be rendered using Mermaid-compatible tools such as Mermaid Live Editor,
Markdown preview extensions, or documentation platforms that support Mermaid.

## Diagram List

- `system_context_diagram.mmd`: shows external actors and system context.
- `use_case_diagram.mmd`: shows primary users and core use cases.
- `erd.mmd`: shows the conceptual entity relationship model.
- `member_subscription_flow.mmd`: shows registration and subscription flow.
- `payment_flow.mmd`: shows payment recording and follow-up flow.
- `class_booking_flow.mmd`: shows class scheduling, booking, and attendance.

All diagrams are conceptual planning diagrams. They are not proof of production
deployment.

No PNG diagram files are included.
