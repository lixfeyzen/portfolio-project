# Market Feature Benchmark

## Purpose

This benchmark compares public gym management software feature patterns against
the ProfitHub MVP scope. It is used only to support general feature relevance.

| Source | Relevant Features Observed | Relevance to ProfitHub MVP |
| --- | --- | --- |
| [Glofox][glofox] | Membership, class booking, billing/payment, reporting, mobile app. | Supports member, class, payment, dashboard. Mobile app is future scope. |
| [GymMaster][gymmaster] | Member records, memberships, class/trainer booking, sales tracking. | Supports member, subscription, trainer, schedule, payment. |
| [GymDesk][gymdesk] | Billing, attendance, member management, failed payment tracking, capacity. | Supports payment, attendance, member status, capacity. |
| [RhinoFit][rhinofit] | Membership, automatic billing, attendance, reporting, class calendar. | Supports subscription, payment, attendance, reporting, schedule. |

## Conclusion

The benchmark shows that ProfitHub MVP modules align with common gym management
software patterns.

The MVP intentionally excludes larger features such as member mobile app,
payment gateway integration, and multi-branch management.
