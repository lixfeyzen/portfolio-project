# Primary Validation Plan

## Purpose

This plan describes how ProfitHub could be validated with real gym stakeholders
in a future phase. No interview findings are claimed in the current case study.

## Target Respondents

- Gym owner
- Admin / Receptionist
- Trainer

## Interview Questions

1. How do you currently track active and expired memberships?
2. How do you follow up unpaid members?
3. How do you manage class schedules and trainer availability?
4. What information does the owner need every week or month?
5. What problems happen most often with manual records?
6. What dashboard or report would be most useful?
7. Which features are must-have for MVP and which can wait?

## Validation Goals

- Confirm whether member status tracking is a real operational pain point.
- Confirm payment follow-up and overdue tracking needs.
- Understand how trainer schedules and class capacity are currently managed.
- Validate owner dashboard metric priorities.
- Separate must-have MVP functions from future enhancements.

## How Findings Would Update the MVP

- Requirements would be adjusted only when validated pain points are clear.
- Business rules would be refined based on actual operating policies.
- Dashboard metrics would be prioritized based on owner decision needs.
- Future backlog items would be reprioritized based on stakeholder feedback.

## Ethical Note

No interview results should be added unless interviews are actually conducted.

Any future interview notes should be anonymized and should avoid confidential
business, financial, or member data.
