# Wireframe Notes

The wireframes in this project are text-based planning notes only. They describe expected page structure, content areas, and workflow intent for future UI design or prototyping.

## Admin Dashboard

Purpose: Give owners and admins a quick operational view of members, payments, revenue, classes, and trainer load.

Expected sections:

- KPI cards
- Revenue summary
- Active members
- Expired members
- Unpaid members
- Popular classes
- Trainer schedule load

## Member Management

Purpose: Help admins search, filter, and manage member records.

Expected sections:

- Search and filter area
- Member table
- Status chips
- Action buttons for view, edit, and subscription assignment

## Member Detail

Purpose: Provide a single operational record for each member.

Expected sections:

- Member profile
- Current subscription summary
- Subscription history
- Payment history
- Class booking history

## Payment Tracking

Purpose: Help admins record payments and follow up unpaid or overdue members.

Expected sections:

- Unpaid member list
- Payment record form
- Payment history table
- Overdue indicator

## Class Schedule

Purpose: Help admins manage class schedules, trainer assignment, booking list, and attendance workflow.

Expected sections:

- Class calendar or schedule list
- Trainer assignment
- Capacity indicator
- Booking list
- Attendance checklist
