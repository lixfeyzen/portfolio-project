# Admin Dashboard Wireframe Notes

## Page Purpose

Provide a quick operational summary for owners and authorized admins.

The page should support fast scanning, not deep accounting.

## Layout Sections

### KPI Cards

- Active Members
- Expired Members
- Unpaid Members
- New Members This Month
- Monthly Revenue

### Revenue Summary

- Current month paid payment total
- Payment status breakdown
- Link to payment tracking page

### Active Members

- Count of active members
- Recent active member list
- Link to member management

### Expired Members

- Count of expired members
- List sorted by most recent expiration
- Renewal follow-up action

### Unpaid Members

- Unpaid and overdue count
- Member name, amount, due date, and status
- Link to record payment

### Popular Classes

- Class name
- Booking count or attendance count
- Date range filter

### Trainer Schedule Load

- Trainer name
- Number of assigned classes
- Upcoming class list
