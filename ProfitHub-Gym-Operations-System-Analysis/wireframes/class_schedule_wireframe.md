# Class Schedule Wireframe Notes

## Page Purpose

Help admins manage class schedules and bookings while giving trainers a clear attendance workflow.

## Class Calendar

- Daily or weekly schedule view.
- Class name, trainer, time, capacity, and status.
- Filters by trainer, class type, and status.

## Trainer Assignment

- Trainer dropdown shows active trainers.
- System checks overlapping schedules before save.
- Conflict message appears when the trainer is already assigned to another class at the same time.

## Class Capacity

- Display maximum capacity.
- Display current booking count.
- Show full status when capacity is reached.

## Booking List

Columns:

- Member Name
- Membership Status
- Booking Status
- Booking Date
- Action

## Attendance Checklist

- Booked member list.
- Present, absent, and late options.
- Save attendance action.
- Attendance history visible from member detail.
