# Member Detail Wireframe Notes

## Page Purpose

Provide a complete operational view of one member, including profile, subscription, payment, and booking history.

## Member Profile

- Full name
- Phone number
- Email
- Date of birth
- Join date
- Current member status
- Edit profile action

## Current Subscription Summary

- Current plan
- Start date
- End date
- Subscription status
- Expiring soon indicator when applicable

## Subscription History

Columns:

- Plan
- Start Date
- End Date
- Status
- Created Date

## Payment History

Columns:

- Payment Date
- Amount
- Payment Method
- Payment Status
- Due Date
- Recorded By

## Class Booking History

Columns:

- Class Name
- Trainer
- Class Date
- Booking Status
- Attendance Status

## Key Actions

- Assign or renew plan
- Record payment
- Book class
- Update member status
