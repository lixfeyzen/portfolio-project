# Member Management Wireframe Notes

## Page Purpose

Allow admins to search, filter, add, and manage member records from a single operational page.

## Search / Filter

- Search by name, phone number, or email.
- Filter by status: active, expired, unpaid, inactive, expiring soon.
- Optional join date range filter.

## Member Table

Columns:

- Member Name
- Phone Number
- Email
- Current Status
- Current Plan
- Subscription End Date
- Last Payment Status
- Actions

## Status Chips

- Active
- Expired
- Unpaid
- Inactive
- Expiring Soon

## Action Buttons

- View Detail
- Edit Member
- Assign Plan
- Record Payment
- Book Class

## Empty State

Show a clear empty state when no members match the selected filter.
